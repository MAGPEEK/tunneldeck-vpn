# File map

- `CLAUDE.md` — commands and rules for every agent
- `LICENSE` — MIT licence
- `CHANGELOG.md` — Keep a Changelog; add user-visible changes under `Unreleased`
- `go.mod` — Go module `tunneldeck`; `ignore ./web/node_modules` keeps npm packages out of `./...`
- `.golangci.yml` — golangci-lint v2 config (govet, staticcheck, errcheck, ineffassign, unused, revive, misspell, gofmt, goimports)
- `Dockerfile` — multi-stage build: Node (frontend) → Go (static binary incl. the embedded wireguard-go, `VERSION`/`REVISION` build args) → strongSwan 6.0.7 charon from source (checksum-pinned, kernel-libipsec with the patch from `build/strongswan/`, IKEv2 + IKEv1, only the loaded plugins) → Alpine runtime with openvpn 2.7, charon, iptables, tzdata; OCI labels, `HEALTHCHECK`, root rationale
- `build/strongswan/` — patches applied to strongSwan in the image build: `kernel-libipsec-install-routes.patch` makes kernel-libipsec honour `install_routes = no`, so charon never routes on the host
- `.dockerignore` — keeps docs, VCS data, node_modules and local build output out of the image context
- `.gitattributes` — LF endings for shell scripts
- `docker-compose.yml` — local use: host network, `NET_ADMIN`, `/dev/net/tun`, `./data:/data`, optional env vars as comments
- `deploy/synology/docker-compose.yml` — Synology Container Manager project, data in `/volume1/docker/tunneldeck`
- `scripts/version.sh` — derives `VERSION`, `REVISION`, image `TAG` from `git describe` (sourced by the two scripts below)
- `scripts/build-image.sh` — builds `magpeek/tunneldeck-vpn:<tag>` with version build args; no push
- `scripts/export-image.sh` — `docker save` to `tunneldeck-<tag>.tar` for Synology import
- `docs/synology.md`, `docs/synology.de.md` — DS723+ / DSM 7.2 guide: TUN module, project, first sign-in, firewall, reverse proxy, remote access, backup, update, reset-admin, firewall rules (IP forwarding on DSM, LANCOM IPsec example)
- `docs/reset-admin.md`, `docs/reset-admin.de.md` — lost admin password: what a reset keeps, `reset-admin` command (Docker, Synology SSH/Container Manager), `TUNNELDECK_RESET_ADMIN` and why to remove it, security note
- `docs/linux.md`, `docs/linux.de.md` — generic Linux Docker host guide: requirements, compose, first sign-in, iptables backends next to Docker/ufw/firewalld, reverse proxy, remote access, backup, update, reset-admin, firewall rules (concepts, `#ip-forwarding` / `#ip-weiterleitung` linked from the UI, IPsec router example with what was lab-tested)
- `docs/ipsec.md`, `docs/ipsec.de.md` — IPsec/IKEv2 gateway guides: how TunnelDeck talks to the gateway, form fields, LANCOM, FRITZ!Box (user access IKEv1 XAuth field mapping, LAN-to-LAN), OPNsense/pfSense/strongSwan (swanctl example), net-to-net static route, troubleshooting
- `docs/system-checks.md` — System page self-check entries: meaning of OK/warning/failure, kernel module, fix on Linux and DSM
- `docs/system-checks.de.md` — German version of the System page checks explanation
