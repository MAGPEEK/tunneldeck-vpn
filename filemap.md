# File map

- `CLAUDE.md` — commands and rules for every agent
- `LICENSE` — MIT licence
- `CHANGELOG.md` — Keep a Changelog; add user-visible changes under `Unreleased`
- `go.mod` — Go module `tunneldeck`; `ignore ./web/node_modules` keeps npm packages out of `./...`
- `.golangci.yml` — golangci-lint v2 config (govet, staticcheck, errcheck, ineffassign, unused, revive, misspell, gofmt, goimports)
- `Dockerfile` — multi-stage build: Node (frontend) → Go (static binary, `VERSION`/`REVISION` build args) → Alpine runtime with openvpn 2.7, iptables, tzdata; OCI labels, `HEALTHCHECK`, root rationale
- `.dockerignore` — keeps docs, VCS data, node_modules and local build output out of the image context
- `.gitattributes` — LF endings for shell scripts
- `docker-compose.yml` — local use: host network, `NET_ADMIN`, `/dev/net/tun`, `./data:/data`, optional env vars as comments
- `deploy/synology/docker-compose.yml` — Synology Container Manager project, data in `/volume1/docker/tunneldeck`
- `scripts/version.sh` — derives `VERSION`, `REVISION`, image `TAG` from `git describe` (sourced by the two scripts below)
- `scripts/build-image.sh` — builds `magpeek/tunneldeck-vpn:<tag>` with version build args; no push
- `scripts/export-image.sh` — `docker save` to `tunneldeck-<tag>.tar` for Synology import
- `docs/synology.md`, `docs/synology.de.md` — DS723+ / DSM 7.2 guide: TUN module, project, first sign-in, firewall, reverse proxy, remote access, backup, update, reset-admin, firewall rules (IP forwarding on DSM, LANCOM IPsec example)
- `docs/linux.md`, `docs/linux.de.md` — generic Linux Docker host guide: requirements, compose, first sign-in, iptables backends next to Docker/ufw/firewalld, reverse proxy, remote access, backup, update, reset-admin, firewall rules (concepts, `#ip-forwarding` / `#ip-weiterleitung` linked from the UI, IPsec router example with what was lab-tested)
- `test/e2e/` — end-to-end test (build tag `e2e`, `go test -tags e2e ./test/e2e/`): `compose.yml` (three OpenVPN servers, three TunnelDeck hosts: only legacy, only nft, both with a host rule in nft; for the firewall a LAN network with two TunnelDeck hosts, nft and legacy, `lan-web`, `lan-ipsec` and `peer-ipsec` in server-a's namespace), Go driver (`e2e_test.go` scenario, `matrix_test.go` variants and backends, `tunneldeck_test.go` API steps, `client_test.go` HTTP client, `stack_test.go` docker compose, `lan_test.go` firewall cases: migration, port forwards, outbound routing, kill switch; `ipsec_test.go` IPsec template, IKEv2 with NAT-T and manually keyed ESP), `server/` test-server image (configs per variant, throwaway PKI, verify script, dummy network 10.99.0.0/24 behind the server), `node/` LAN/IPsec node image (busybox httpd with a client-address CGI, strongSwan), `testdata/settings-v1.json` (schema-1 settings with two host-access rules); topology in `README.md`
- `docs/migrate-from-rut240.md`, `docs/migrate-from-rut240.de.md` — RUT240 field and extra-option mapping, mdex example, level 30 recommendation
- `docs/RELEASING.md` — release steps: changelog, tag, build, smoke test, image tags
- `.github/workflows/ci.yml` — CI: frontend lint/test/build, Go build/test/lint, e2e matrix, Docker build (no push)
- `docs/SPEC.md` — specification; change only with the orchestrator
- `docs/PLAN.md` — task list and status
- `docs/openvpn-notes.md` — lab-verified OpenVPN 2.7 facts: directives, management dialogue, reference config; binding for the driver
- `docs/reference/original-compose.yml` — original Alpine/OpenVPN compose this project replaces
- `cmd/tunneldeck/` — entry point: subcommands `serve`/`reset-admin`/`healthcheck` (`main.go`), health probe of the UI listener (`healthcheck.go`), wiring, startup order and graceful shutdown (`serve.go`), listen-address detection (`listen.go`), auth/cookie/import adapters for the API (`adapters.go`), `reset-admin` via control socket or store (`reset.go`)
- `internal/config/` — SPEC §10 environment → validated `Config` (`config.go`)
- `internal/control/` — root-only unix control socket (`control.sock`, one-line protocol) for `reset-admin`; SO_PEERCRED check in `peer_linux.go`, fallback in `peer_other.go`
- `internal/domain/` — core types: Profile (generic Settings plus Secrets), PublicProfile/hasValue, DailyReconnect, Firewall/FirewallSettings/FirewallRule with PortRange (empty = any port) and the "Host" destination (`firewall.go`) and their validation, reserved-port and LAN checks (`firewall_validate.go`), HostNetwork and the "IPsec device" template rules (`firewall_template.go`), RemoteAccess/KeyPair, events, DesiredConnection, AdminAccount, sentinel errors and ValidationError with coded FieldIssues (`errors.go`), NewID
- `internal/vpn/` — `Driver`, `Secrets` and the optional `RemoteNetworker` (`driver.go`), `Advisory` (`advisory.go`), `FormSchema` with `Condition` (setting or secret) and its validation (`schema.go`), driver `Registry` (`registry.go`), Clock (`clock.go`), ConnectionManager and its interfaces (`manager.go`), its state machine (`loop.go`, `loop_events.go`), Status (`status.go`), backoff and daily schedule (`schedule.go`), log ring (`logring.go`)
- `internal/vpn/vpntest/` — FakeClock, test-only
- `internal/vpn/openvpn/` (runtime) — Driver (`driver.go`), process supervision (`supervisor.go`), management dialogue (`session.go`), line parser (`management.go`), log levels (`logline.go`), seams (`system.go`), `Pdeathsig` (`process_linux.go`, no-op `process_other.go`)
- `internal/vpn/openvpn/` (config) — keys, `Validate`/`ValidateWithLAN` and `RemoteNetworks` (`settings.go`), `Render` (`render.go`), `ImportOVPN` (`importer.go`), `Advise` (`advisory.go`), `Describe` (`schema.go`), `Warning` (`warning.go`), tokenizer (`directive.go`), denylist (`classify.go`, `extra.go`), PEM/static-key/PKCS#12 checks (`pem.go`); golden files and `.ovpn` samples in `testdata/`
- `internal/remoteaccess/` — SPEC §8.1 HTTPS listener: self-signed certificate, `Describe`, fingerprint and renewal rule (`certificate.go`), upload validation (`upload.go`), `Manager` with listener lifecycle, certificate rotation and daily renewal (`manager.go`)
- `internal/netguard/` — CommandRunner/ExecRunner (`runner.go`), Guard (`guard.go`), iptables backend detection and `TUNNELDECK_IPTABLES` preference (`backend.go`), `InstallFirewall`/`RemoveFirewall` and the remote-access port (`firewall.go`), chain refill, jumps and conntrack fallback (`chains.go`), rendering of the four TUNNELDECK chains from the firewall rules (`ruleset.go`), LAN subnet and host-network detection (`lan.go`), policy rules 7100/7180/7190/7191 incl. remote networks (`policy.go`), tunnel routing table 7194 (`routing.go`), startup self-check incl. ip_forward and LAN (`selfcheck.go`), error types (`errors.go`); integration test behind `integration && linux`
- `internal/store/` — settings.json and profiles.json with atomic writes, a mutex, schemaVersion migrations (`document.go`), settings v1 → v2 firewall migration (`migrate_settings.go`, fixture `testdata/settings-v1.json`), firewall settings and rules (`settings.go`), remote-access setting and encrypted certificate slots (`remoteaccess.go`) and a file-system seam (`atomic.go`)
- `internal/secret/` — AES-256-GCM `enc:v1:` Cipher; `secret.key` load/create and `TUNNELDECK_SECRET_KEY` override
- `internal/auth/` — admin setup/reset, argon2id hashing (`password.go`), in-memory sessions (`session.go`), login rate limit (`ratelimit.go`), session cookie helpers (`cookie.go`); `service.go` is the entry point
- `internal/api/` — REST API per SPEC §9: consumed interfaces (`deps.go`), routes and 404/405 (`server.go`), session/CSRF/logging middleware (`middleware.go`), RFC 9457 errors incl. the `fieldCodes` extension (`problem.go`), JSON body rules (`json.go`), handlers (`session.go`, `profiles.go`, `connection.go`, `firewall.go` — `/api/firewall`, the IPsec template and the 410 for `/api/host-access`, `system.go`, `remoteaccess.go`), HTTPS-listener marker, HSTS and login-limit selection (`https.go`), SSE (`events.go`); fakes in `fakes_test.go`
- `internal/web/` — `go:embed all:dist` of the SPA with fallback to `index.html`
- `internal/web/dist/` — Vite build output (git-ignored); only the committed `.gitkeep` is tracked, so `go build` works without a frontend build, and a Vite plugin re-creates it after each build
- `web/` — React 19 + TypeScript + Vite app; `npm run build` writes to `internal/web/dist`
- `web/src/` — app sources (`main.tsx`, `App.tsx`) and tests; `web/src/test/setup.ts` wires jest-dom into Vitest
- `web/src/styles/` — design tokens (light/dark) and base styles
- `web/src/api/` — `request()` wrapper, `ApiError` (RFC 9457, with `fieldCodes`), field errors in the UI language (`fieldErrors.ts`), typed calls per resource (session, system, profiles/drivers/import, connection/logs, firewall incl. the IPsec template, remote access), shared query keys (`queryKeys.ts`)
- `web/src/session/` — query client (401 → signed out), session hooks, `SessionGate` routing
- `web/src/i18n/` — i18next setup, `de.json`/`en.json`, flat driver label files `drivers.de.json`/`drivers.en.json` and run-time key helpers (`dynamic.ts`), language switch, key-parity test
- `web/src/theme/` — theme storage and toggle
- `web/src/layout/` — `AppShell` (sidebar/top bar), `AuthLayout`, `Page`
- `web/src/components/` — shared Button, Card, Field, StatePill, EmptyState, Table (with optional detail row and highlighted-row state), Notice
- `web/src/advisories/` — advisory list (dashboard) and notice (profile form)
- `web/src/format/` — pure formatters: bytes, bit rates, durations, clock and zoned time
- `web/src/live/` — `LiveEvents` (one EventSource on `/api/events` feeding the query cache, reconnect with backoff), log line append/filter helpers
- `web/src/queries/` — TanStack Query hooks per resource and connection control mutations
- `web/src/hooks/` — `useNow` ticking clock
- `web/src/pages/` — setup and login; `dashboard/` (connection card, metrics, host protection, log); `profiles/` (list, import panel, `form/` profile editor with protocol chooser, schedule and import warnings, `schema/` generic `SchemaForm` renderer; `schemaValues.ts` evaluates `visibleWhen` for setting and secret conditions); `firewall/` (Firewall page: inbound/outbound tabs `DirectionTabs`, `RuleTable` with reordering, inline `RuleEditor`, `IpsecTemplateForm`, `ProtectionCard`, `HostContext` line; `ruleDraft.ts` converts, validates port text, reorders and maps API field errors; `ruleText.ts` formats protocol and route); `system/` (version, self-check, remote access)
- `web/src/test/` — Vitest setup, fetch mock, fake EventSource, fixtures (OpenVPN schema, profiles, status), `renderApp`/`renderWithProviders` helpers
- `web/vite.config.ts` — build output, `/api` dev proxy to `127.0.0.1:8194`, Vitest config
- `web/eslint.config.js` — ESLint flat config (typescript-eslint strict, react-hooks, prettier)
